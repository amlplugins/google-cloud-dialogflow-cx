# @amlplugins/google-cloud-dialogflow-cx

Native `@google-cloud/dialogflow-cx` SDK re-exported under the `@amlplugins` namespace.

> Dialogflow CX.

## Install

```bash
npm install @amlplugins/google-cloud-dialogflow-cx
```

## Use

```ts
import { /* named exports from @google-cloud/dialogflow-cx */ } from "@amlplugins/google-cloud-dialogflow-cx";
// or
import sdk from "@amlplugins/google-cloud-dialogflow-cx";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
